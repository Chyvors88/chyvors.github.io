# Portfolio photo cleanup

Edited with the built-in image generation tool using each supplied original as the edit target.

Use case: precise-object-edit. Edit target: the supplied real project photograph. Create a high-definition, professionally retouched portfolio photograph for backdropped. Remove loose floor scraps, litter, discarded packaging, stray unused tools, temporary clutter and distracting unrelated items where present; naturally reconstruct the existing floor and surroundings. Keep purposeful display products and permanent fixtures. Improve exposure, neutral colour balance, crisp detail, straight composition and polished natural lighting. Preserve the exact installed work, materials, proportions, client branding, every printed letter, logos and artwork. Do not invent or redesign the installation, remove watermarks, or add props. Keep original aspect ratio and realistic textures, avoid artificial HDR. Deliver the highest available native resolution with sharp readable signage. For artwork/business cards preserve their exact design and typography and simply produce a clean crisp reproduction. For process photographs retain workers and tools actively in use but tidy discarded clutter.


Full native-resolution edits are paired with the original photographs in the portfolio viewer. Web thumbnails are separate files; no artificial upscaling is applied.
